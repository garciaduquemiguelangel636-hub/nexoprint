# NexoPrint

### Sistema inteligente para la gestión de pedidos de papelería y fotocopiadora

NexoPrint es una aplicación desarrollada en Python que busca facilitar y organizar la gestión de pedidos en papelerías y centros de fotocopiado. Su propósito es mejorar la comunicación entre clientes y administradores, permitiendo realizar seguimiento de los pedidos de manera sencilla y ordenada.

## Características principales

### Para los clientes

- Registrar nuevos pedidos.
- Consultar el estado de sus pedidos.
- Visualizar el tiempo estimado de entrega.
- Cancelar pedidos cuando sea necesario.
- Confirmar la recepción de un pedido.
- Consultar el historial de pedidos.

### Para los administradores

- Iniciar sesión mediante una cuenta de administrador.
- Consultar y gestionar los pedidos registrados.
- Modificar el estado de los pedidos.
- Establecer y actualizar los tiempos estimados de entrega.
- Mantener un mejor control de las solicitudes de los clientes.

## Gestión automática de pedidos

NexoPrint incorpora funciones para facilitar el seguimiento de los pedidos:

- Los tiempos estimados permiten informar al cliente sobre la entrega.
- El sistema puede actualizar el estado de los pedidos según las condiciones programadas.
- El cliente puede confirmar que recibió su pedido, permitiendo marcarlo como entregado.

## Tecnologías utilizadas

- **Python:** lenguaje principal de programación.
- **Interfaz gráfica:** para facilitar la interacción entre clientes y administradores.
- **Gestión de datos:** almacenamiento y consulta de la información de los pedidos.

## Objetivo del proyecto

Desarrollar una herramienta tecnológica que permita optimizar los procesos de atención en papelerías y fotocopiadoras, reduciendo la desorganización, facilitando el seguimiento de los pedidos y mejorando la experiencia tanto de los clientes como de los administradores.

## Instalación y ejecución

1. Descargar o clonar este repositorio.
2. Tener Python instalado en el equipo.
3. Abrir la carpeta del proyecto.
4. Ejecutar el archivo principal de Python desde Visual Studio Code o una terminal.

Ejemplo:

```bash
python NexoPrint_corregido.py
```

*Nota: el nombre del archivo puede variar según la versión del proyecto.*
